# VASIXZZ CHESS AI V1.0

Android-тренажёр: интерактивная шахматная доска, легальные ходы через chess.js, загрузка позиции FEN, отмена хода и попытка получить оценку позиции из Lichess Cloud Eval.

## Сборка APK только с телефона
1. Создай репозиторий на https://github.com/.
2. Распакуй архив и загрузи ВСЕ файлы проекта в корень репозитория, включая скрытую папку `.github`.
3. Открой вкладку Actions → Build VASIXZZ CHESS AI APK → Run workflow.
4. После успешной сборки открой запуск workflow и скачай артефакт `VASIXZZ-CHESS-AI-APK`.
5. Распакуй скачанный ZIP и установи `app-debug.apk`.

## Ограничения версии 1.0
- Приложение работает как отдельный тренировочный тренажёр; оно не подключается к Chess.com, не распознаёт экран другого приложения и не накладывает подсказки на рейтинговые партии.
- Оценка хода запрашивается у Lichess Cloud Eval. В облачной базе есть не все позиции; при отсутствии позиции оценка будет недоступна.
- Метки в этой версии приблизительные. «Возможная жертва» не является официальной меткой Brilliant Chess.com.
- Для загрузки chess.js и обращения к облачной базе нужен интернет.
